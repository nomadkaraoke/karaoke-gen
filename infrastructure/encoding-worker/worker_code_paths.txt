# Paths whose changes require a blue-green redeploy of the GCE encoding worker.
#
# CI (.github/workflows/ci.yml, "Decide encoding-worker deploy") diffs these
# paths between the version the serving worker was last validated at
# (config/encoding-worker.primary_version → git tag v<version>) and HEAD. No
# diff → the fresh-green boot + test encode + swap is skipped (it used to run on
# every push to main). The wheel/startup.sh/version.txt are STILL uploaded to
# GCS on every deploy, so any worker that cold-boots picks up the latest wheel.
#
# The worker process runs backend/services/gce_encoding/main.py and imports
# karaoke_gen (render/encode) plus a few backend modules.
# backend/tests/test_encoding_worker_code_paths.py derives that import closure
# and fails if a module the worker imports is not covered here — so adding a new
# worker import can't silently bypass the gate.
#
# One git pathspec per line; blank lines and # comments are ignored.
